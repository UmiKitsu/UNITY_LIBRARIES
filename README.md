# 🎮 UNITY_LIBRARIES

A collection of **useful Unity scripts** and **reusable code libraries** designed to speed up development and promote clean, maintainable, and scalable architecture across multiple Unity projects.

---

## 🧩 Overview

This repository contains modular and flexible Unity scripts that can be used in various types of games — from 2D to 3D projects.  
Each script focuses on providing **common functionalities**, **best practices**, and **performance-friendly solutions** that you can easily integrate into your own projects.

---

## 📁 Example Contents

### 🔧 Example.References
Contains an example implementation of **Dependency Injection** to help decouple systems and make your project more modular and testable.

### 🎮 Script/2D/NPC Behavior
Includes a **LookAtPlayer2D** script — a simple but effective behavior for NPCs to always face the player’s direction.

---

## 🚀 Purpose

The goal of this repository is to build a **shared Unity library** containing reusable, well-structured scripts that solve common development problems.  
Instead of rewriting the same code for every new project, simply import what you need from here.
